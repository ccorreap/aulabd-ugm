# Proyecto: AulaBD UGM - Cátedra de Base de Datos

## Descripción del Proyecto
Plataforma educativa interactiva para la asignatura **Base de Datos** de la carrera de **Ingeniería en Computación e Informática** en la **Universidad Gabriela Mistral**.

- **Docente:** Mag. Cristian Correa Pacheco (`CRISTIAN.CORREA@academico.ugm.cl`)
- **Motor de Base de Datos principal:** Microsoft SQL Server
- **Tecnologías:** Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide Icons

## Comandos Principales
- Iniciar entorno local: `npm run dev` (disponible en http://localhost:3000)
- Compilar para producción: `npm run build`
- Despliegue en GCP Cloud Run: `gcloud run deploy aulabd-ugm --source . --region southamerica-west1 --allow-unauthenticated`

## Estructura de Clases
- **Clase 1:** Conceptos Básicos, Glosario y Tipos de Datos (SQL Server) [Cátedra Nº 2]
- **Clase 2:** Fundamentos de Sistemas de Información, Modelos y Requerimientos TI [Cátedra Nº 3]
- **Clase 3:** Modelado de Datos: Conceptual, Lógico y Físico (MER) [Cátedra Nº 4]
- **Clase 4:** Modelos Gráficos UML: Casos de Uso y Diagramas de Clases [Cátedra Nº 5]
- **Clase 5:** Normalización de Bases de Datos: 1FN, 2FN y 3FN [Cátedra Nº 5 Parte 2]
- **Clase 6:** SQL Server DDL: CREATE, ALTER, DROP vs TRUNCATE [Cátedra Nº 7]
- **Clase 7:** SQL Server DML, Consultas SELECT, Índices y Vistas [Cátedra Nº 8]
